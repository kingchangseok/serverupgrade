## 🏗️ 빌드 프로세스

### Makefile 분석

```makefile
CC      = cc
CFLAGS  = -g
SUBDIR  = aessrc ftpsrc md5src svrsrc tarsrc 
TARGET  = ecams_svr
LIBS    = -lxnet -lnsl
```

**빌드 순서**:
1. `aessrc` → AES 암호화 라이브러리 컴파일
2. `ftpsrc` → FTP 소스 컴파일 (파일 누락, 참조만 존재)
3. `md5src` → MD5 해시 라이브러리 컴파일
4. `svrsrc` → 메인 서버 소스 컴파일
5. `tarsrc` → TAR 처리 라이브러리 컴파일
6. **링킹**: `object/*.o` 파일을 `ecams_svr` 실행 파일로 링크
7. **설치**: `bin/` 디렉토리로 실행 파일 이동
8. `fileinf` → 파일 정보 처리 컴파일 (디렉토리 누락)

```c
{
    // ...
}

// 개선 후 (ANSI C 스타일)
int ProcSystemCmd(int Sock, char *RdBuf, int RdLng)
{
    // ...
}
```

##### 1.2 헤더 파일 정리
- 모든 함수 프로토타입을 ANSI C 형식으로 변경
- `ecams_funclist.h`의 함수 선언을 명확한 타입으로 수정
- 중복된 extern 선언 제거


```c
int SafeFileOpen(const char *path, int flags, mode_t mode, int *fd) 
{
    if (!path || !fd) {
        Agent_log("SafeFileOpen: Invalid parameters");
        return ECAMS_ERR_INVALID_PARAM;
    }
    
    *fd = open(path, flags, mode);
    if (*fd < 0) {
        char err_msg[256];
        snprintf(err_msg, sizeof(err_msg), 
                 "Failed to open file %s: %s", path, strerror(errno));
        Agent_log(err_msg);
        return ECAMS_ERR_FILE_OPEN;
    }
    
    return ECAMS_SUCCESS;
}
```

#### 3. 로깅 시스템 개선 (구조화된 로그)

**현재 문제점**:
- `Agent_log()` 함수가 단순 문자열만 지원
- 로그 레벨 구분 없음
- 타임스탬프, 스레드 ID 등 메타데이터 부족
- 로그 파일 로테이션 미지원

**개선 방안**:

##### 3.1 로그 레벨 정의
```c
// inc/ecams_log.h (신규 생성)
typedef enum {
    LOG_LEVEL_DEBUG   = 0,
    LOG_LEVEL_INFO    = 1,
    LOG_LEVEL_WARN    = 2,
    LOG_LEVEL_ERROR   = 3,
    LOG_LEVEL_FATAL   = 4
} log_level_t;

// 로그 설정
typedef struct {
    log_level_t min_level;      // 최소 로그 레벨
    char log_dir[256];          // 로그 디렉토리
    int max_file_size;          // 최대 파일 크기 (MB)
    int max_backup_files;       // 백업 파일 개수
    int enable_console;         // 콘솔 출력 여부
} log_config_t;

// 전역 로그 설정
extern log_config_t g_log_config;
```

##### 3.2 구조화된 로그 함수
```c
// svrsrc/logging.c (신규 생성)
void ecams_log(log_level_t level, const char *file, int line, 
               const char *func, const char *format, ...)
{
    if (level < g_log_config.min_level) return;
    
    char timestamp[32];
    char log_msg[1024];
    char final_msg[1200];
    va_list args;
    
    // 타임스탬프 생성
    time_t now = time(NULL);
    strftime(timestamp, sizeof(timestamp), "%Y-%m-%d %H:%M:%S", 
             localtime(&now));
    
    // 로그 메시지 포맷팅
    va_start(args, format);
    vsnprintf(log_msg, sizeof(log_msg), format, args);
    va_end(args);
    
    // 최종 로그 라인 생성
    snprintf(final_msg, sizeof(final_msg),
             "[%s] [%s] [PID:%d] [%s:%d:%s] %s\n",
             timestamp,
             log_level_to_string(level),
             getpid(),
             file, line, func,
             log_msg);
    
    // 파일에 쓰기
    write_to_log_file(final_msg);
    
    // 콘솔 출력 (설정에 따라)
    if (g_log_config.enable_console) {
        fprintf(stderr, "%s", final_msg);
    }
}

// 편의 매크로
#define LOG_DEBUG(...) ecams_log(LOG_LEVEL_DEBUG, __FILE__, __LINE__, __func__, __VA_ARGS__)
#define LOG_INFO(...)  ecams_log(LOG_LEVEL_INFO,  __FILE__, __LINE__, __func__, __VA_ARGS__)
#define LOG_WARN(...)  ecams_log(LOG_LEVEL_WARN,  __FILE__, __LINE__, __func__, __VA_ARGS__)
#define LOG_ERROR(...) ecams_log(LOG_LEVEL_ERROR, __FILE__, __LINE__, __func__, __VA_ARGS__)
#define LOG_FATAL(...) ecams_log(LOG_LEVEL_FATAL, __FILE__, __LINE__, __func__, __VA_ARGS__)
```

##### 3.3 로그 파일 로테이션
```c
// 로그 파일 크기 체크 및 로테이션
void check_and_rotate_log(void)
{
    struct stat st;
    char old_log[300], new_log[300];
    
    if (stat(current_log_file, &st) != 0) return;
    
    // 파일 크기 체크 (MB 단위)
    if (st.st_size < g_log_config.max_file_size * 1024 * 1024) {
        return;  // 로테이션 불필요
    }
    
    // 기존 백업 파일들 이름 변경 (log.3 -> log.4, log.2 -> log.3, ...)
    for (int i = g_log_config.max_backup_files - 1; i >= 1; i--) {
        snprintf(old_log, sizeof(old_log), "%s/ecams_svr.log.%d", 
                 g_log_config.log_dir, i);
        snprintf(new_log, sizeof(new_log), "%s/ecams_svr.log.%d", 
                 g_log_config.log_dir, i + 1);
        rename(old_log, new_log);
    }
    
    // 현재 로그를 .1로 변경
    snprintf(new_log, sizeof(new_log), "%s/ecams_svr.log.1", 
             g_log_config.log_dir);
    rename(current_log_file, new_log);
    
    // 새 로그 파일 생성
    log_fd = open(current_log_file, O_WRONLY | O_CREAT | O_APPEND, 0644);
}
```
