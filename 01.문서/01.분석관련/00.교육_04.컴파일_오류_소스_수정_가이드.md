## 1. Deprecated 함수 치환

### 문제 증상
```
warning: 'bzero' is deprecated: use 'memset' instead
warning: 'bcopy' is deprecated: use 'memcpy' instead
```

### 원인
- `bzero`, `bcopy`는 BSD에서 유래한 오래된 함수
- POSIX 표준에서 deprecated 처리됨
- 최신 컴파일러에서 경고 발생

### 해결 방법

#### 1.1. bzero → memset 치환

**잘못된 코드**:
```c
char buffer[256];
bzero(buffer, sizeof(buffer));
```

**올바른 코드**:
```c
char buffer[256];
memset(buffer, 0, sizeof(buffer));
```

**패턴**:
```
bzero(포인터, 크기)  →  memset(포인터, 0, 크기)
```

#### 1.2. bcopy → memcpy 치환

**잘못된 코드**:
```c
char src[100], dst[100];
bcopy(src, dst, 100);
```

**올바른 코드**:
```c
char src[100], dst[100];
memcpy(dst, src, 100);
```

**패턴** (⚠️ 인자 순서 주의!):
```
bcopy(소스, 목적지, 크기)  →  memcpy(목적지, 소스, 크기)
```

#### 1.3. 일괄 치환 방법

**방법 1: sed 명령어 사용** (Linux/Git Bash)
```bash
# bzero 치환
find . -name "*.c" -o -name "*.h" | xargs sed -i.bak \
  's/bzero(\([^,]*\),\s*\([^)]*\))/memset(\1, 0, \2)/g'

# bcopy 치환
find . -name "*.c" -o -name "*.h" | xargs sed -i.bak \
  's/bcopy(\([^,]*\),\s*\([^,]*\),\s*\([^)]*\))/memcpy(\2, \1, \3)/g'
```

**방법 2: 에디터 정규식 찾기/바꾸기** (VS Code 등)

bzero 찾기:
```regex
bzero\(([^,]+),\s*([^)]+)\)
```
bzero 바꾸기:
```
memset($1, 0, $2)
```

bcopy 찾기:
```regex
bcopy\(([^,]+),\s*([^,]+),\s*([^)]+)\)
```
bcopy 바꾸기:
```
memcpy($2, $1, $3)
```


## 2. BSD 타입 정의 추가

### 문제 증상
```
error: unknown type name 'u_char'
error: unknown type name 'u_short'
error: unknown type name 'u_int'
error: unknown type name 'u_long'
```

### 원인
- Alpine Linux, musl libc 등 일부 시스템에서 BSD 타입 미제공
- glibc에서는 `<sys/types.h>`에 포함되어 있으나, musl에는 없음

### 해결 방법

#### 2.1. 공통 헤더 파일에 타입 정의 추가

**파일**: `inc/ecamsapi.h` (또는 프로젝트의 공통 헤더)

**수정 전** (파일의 맨 위):
```c
#ifndef _ECAMSAPI_H_
#define _ECAMSAPI_H_

#include <stdio.h>
#include <stdlib.h>
// ... 기타 헤더
```

**수정 후** (include 블록 다음에 추가):
```c
#ifndef _ECAMSAPI_H_
#define _ECAMSAPI_H_

#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
// ... 기타 헤더

/* BSD compatibility types for Alpine Linux / musl libc */
#ifndef u_char
typedef unsigned char u_char;
typedef unsigned short u_short;
typedef unsigned int u_int;
typedef unsigned long u_long;
#endif

// ... 나머지 코드
```

#### 2.2. 정확한 위치

```c
#ifndef _ECAMSAPI_H_
#define _ECAMSAPI_H_

// 1. 시스템 헤더
#include <sys/types.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// 2. BSD 타입 정의 (여기에 추가!)
#ifndef u_char
typedef unsigned char u_char;
typedef unsigned short u_short;
typedef unsigned int u_int;
typedef unsigned long u_long;
#endif

// 3. 프로젝트 상수 및 구조체
#define MAX_BUFFER 1024
// ...

#endif /* _ECAMSAPI_H_ */
```

#### 2.3. 대안: 조건부 컴파일

특정 시스템에서만 정의가 필요한 경우:

```c
/* Alpine Linux / musl libc에서만 BSD 타입 정의 */
#if !defined(__GLIBC__)
#ifndef u_char
typedef unsigned char u_char;
typedef unsigned short u_short;
typedef unsigned int u_int;
typedef unsigned long u_long;
#endif
#endif
```

## 3. 네트워크 헤더 추가

### 문제 증상
```
warning: implicit declaration of function 'select'
warning: implicit declaration of function 'socket'
warning: implicit declaration of function 'inet_ntoa'
warning: implicit declaration of function 'bzero'
```

### 원인
- 네트워크 관련 함수 프로토타입이 포함된 헤더 미포함
- POSIX 표준 헤더가 누락됨

### 해결 방법

#### 3.1. lanapi.c 헤더 추가

**파일**: `svrsrc/lanapi.c`

**수정 전**:
```c
#include <config.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <netdb.h>
// ... 나머지 코드
```

**수정 후**:
```c
#include <config.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/types.h>
#include <sys/socket.h>
#include <sys/select.h>        /* select() 함수 */
#include <arpa/inet.h>         /* inet_ntoa(), htons() 등 */
#include <strings.h>           /* bzero(), bcopy() (deprecated) */
#include <netinet/in.h>
#include <netdb.h>
// ... 나머지 코드
```

#### 3.2. 필수 네트워크 헤더 정리

| 헤더 파일 | 제공 함수/타입 | 필수 여부 |
|----------|--------------|---------|
| `<sys/types.h>` | 기본 타입 (size_t 등) | ✅ 필수 |
| `<sys/socket.h>` | socket(), bind(), listen() | ✅ 필수 |
| `<sys/select.h>` | select(), FD_SET 등 | ✅ 권장 |
| `<netinet/in.h>` | struct sockaddr_in | ✅ 필수 |
| `<arpa/inet.h>` | inet_ntoa(), htons() | ✅ 필수 |
| `<netdb.h>` | gethostbyname() | ✅ 필수 |
| `<strings.h>` | bzero(), bcopy() | ⚠️ 조건부 |

#### 3.3. 올바른 헤더 순서

```c
/* 1. 설정 헤더 */
#include <config.h>

/* 2. 표준 C 라이브러리 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>

/* 3. 시스템 타입 */
#include <sys/types.h>

/* 4. 네트워크 관련 (순서 중요!) */
#include <sys/socket.h>        /* 먼저 */
#include <sys/select.h>
#include <netinet/in.h>        /* sys/socket.h 다음 */
#include <arpa/inet.h>         /* netinet/in.h 다음 */
#include <netdb.h>

/* 5. 기타 시스템 헤더 */
#include <strings.h>
#include <errno.h>

/* 6. 프로젝트 헤더 */
#include "ecamsapi.h"
```

#### 3.4. 기타 네트워크 관련 파일

같은 방식으로 헤더를 추가해야 할 파일들:

```
svrsrc/lanapi.c    ← 가장 중요
svrsrc/ecams_svr.c
ftpsrc/ftp.c
```

## 4. 검증 방법

### 4.1. 컴파일 전 점검

```bash
# 1. Deprecated 함수가 남아있는지 확인
grep -rn "bzero\|bcopy" . --include="*.c" --include="*.h"

# 2. BSD 타입 정의 확인
grep -n "typedef unsigned char u_char" inc/ecamsapi.h

# 3. 네트워크 헤더 확인
grep -n "#include <sys/select.h>" svrsrc/lanapi.c
```

### 4.2. 컴파일 테스트

```bash
# configure 실행
./configure

# 컴파일 (경고 출력)
make 2>&1 | tee build.log

# 경고 개수 확인
grep -c "warning.*deprecated" build.log
grep -c "warning.*implicit declaration" build.log
```
